# Website demo: Ember & Oak Coffee Roasters (Demo project)

**Demo project / sample build.** Ember & Oak is a fictional business. This is not client work.

Responsive static marketing site in plain HTML/CSS/JS with no frameworks or build step and no external requests.

Features: sticky nav with a mobile menu, hero section, filterable product grid, hours with a live open/closed status, and a contact form with client-side validation. The form is UI-only and sends nothing.

Run: open `index.html`, or `python3 -m http.server 8000` and visit http://localhost:8000.
For a real client, the form would be connected to email, a CRM, or a form service (Formspree, Netlify Forms, etc.), and the site would be deployed to static hosting with a custom domain and HTTPS.
